# torrent

[![Go Reference](https://pkg.go.dev/badge/github.com/richardwilkes/torrent.svg)](https://pkg.go.dev/github.com/richardwilkes/torrent)
[![Build](https://github.com/richardwilkes/torrent/actions/workflows/build.yml/badge.svg)](https://github.com/richardwilkes/torrent/actions/workflows/build.yml)

An implementation of the BitTorrent protocol: http://www.bittorrent.org/beps/bep_0003.html

Implemented:

- BEP-3  The BitTorrent Protocol Specification
- BEP-23 Tracker Returns Compact Peer Lists
- BEP-27 Private Torrents
